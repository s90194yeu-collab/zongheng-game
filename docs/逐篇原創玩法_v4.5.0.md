# 逐篇原創玩法 v4.5.0

本版依課文的行動、器物、空間與限制，重寫先秦諸子、古文十五篇新增章及A類新增章，共35篇97幕、49種實作機制。每種機制只屬於一篇課文；同篇多幕會改變地形、資源或成功條件。原有春秋、戰國、楚漢40話及沿用關卡ID保留。

## 操作與呈現

逐句人物對話、AI場景與原典回讀保留。專用畫面改用可操縱角色、物理器物、戰棋配置、路線規畫、空間解謎或舞臺調度；物件位置、資源及失敗條件各自對應文本。方向鍵／WASD、E、Q、空白及手機按鈕均可操作；庖丁與畫菊亦可直接拖曳操控。

例如庖丁須循骨隙下刀、在聚結處緩行；項脊軒須修漏並將庭牆反光接入北窗；稱仔須移錘、校零、等待力矩穩定；虯髯客前兩幕借梁越巷，末幕改為保留轉向他方的棋局；墨子分守具工程與赴楚越障；散戲則親手接燈、幕、道具提示。

競技保留首輪操作與最佳操作，練習不上競技榜；閱讀首答、訂正與操作分開。這些是單人挑戰及既有成績比較，沒有新增即時多人對戰。

## 內容與存檔

原176題的原典、題幹、選項、答案及解析通過既有SHA256比對。劇情改寫與教學推演標為自編；〈髻〉、〈散戲〉仍是配合課本的自編導讀，不替代全文。遊戲模型不評學生品德或替人物改寫史實。

新開／再戰使用獨立v3操作紀錄。舊v1、v2局中資料仍由舊模型接續，原有首答與首輪不覆寫。已完成篇章可用「再戰本篇・保留首答」體驗新規則。暫停會停計時，離開及重載仍保留本章。修屋亦補齊既有情境存檔的缺欄位，避免重載中斷。

## 驗證範圍

本機46項測試全通過；獨立公開原碼41項通過，5項需私有GAS題庫的測試跳過，這5項已在本機通過。49機制的97幕一般難度均以公開操作事件及固定時間步長求得通關，沒有修改生命、座標或通關旗標；各幕原地連按與放置均無法過關。另驗證JSON續玩、時間步長上限、49種繪圖及專用操作、原題庫、v1／v2／v3計分與首答訂正。

瀏覽器實測、正式版本及畫面釘選見交付驗證紀錄。沒有宣稱人工逐一完整試玩97幕。教師後臺依使用者要求暫不操作；本機測試不提交學校學生作答。
