# 教師自由選關與創意操作 v4.7.0

本次讓教師能直接測試章內指定內容，並把部分新篇章從通用的移動、互動操作，改為實際拼裝、量測、織作、追光、節拍和取景。仍保留逐句劇情、原典閱讀、AI 場景與課後問答。

## 教師如何測試

正式登入的教師帳號會看到「教師自由選關」。一般學生不顯示這個入口；僅在網址加上測試參數不會取得教師權限。

- 春秋、戰國、楚漢原有劇本：可搜尋並直接選擇劇情節點，或直接試玩該節點可辨識的小遊戲。同一節點有多項挑戰時，會分別列出入口。
- 先秦諸子、古文十五篇及經典著作的新章：可指定任一幕看劇情、直接測遊戲，或直接開啟該幕的任一閱讀題。
- 測試中的浮動工具可再次自由選關；「回正式進度」或「結束測試，回原進度」會重新開啟原局。

開始測試前，會先保存原局並等待既有紀錄送出。若原局尚未保存成功，會保留原局，讓教師稍後重試。直接選到後段時，必要的前置局勢採測試起點或未評分示範值，不宣稱教師已完成前面關卡。

教師測試局獨立保存在當頁記憶體中。存檔、首答、首輪分數、訂正、收藏、道具消耗、排行及通關紀錄不會反向合併到正式紀錄；測試中仍可讀取原典題庫與既有成績資訊。退出時重新載入正式進度，不以測試結果覆寫原局。重整測試頁亦不會將測試資料轉為正式存檔。

## 八款核心玩法的實際改造

這八款保留模式 ID 與篇章對應，但新局執行新的操作規則，並有各自的場景繪圖。它們不是把同一套遊戲換名稱。

| 篇章／模式 | 新玩法 | 實際挑戰與限制 |
| --- | --- | --- |
| 老子初階／archive | 斷簡重綴：拖曳拼裝 | 比對左右斷口及墨痕，翻正簡面、卸除遮痕綴飾，再把六簡接入卷面。錯接、倒置或未卸飾會耗損，只有翻面不能完成。 |
| 莊子濠梁選段／haoliang | 濠梁互證：證據串接 | 把橋上與水側的魚跡拉線互證，同時核對尾紋及水層。兩側位置相反，另有不能互證的橋影、水草；不以遊戲結果裁定莊惠辯論誰勝。 |
| 韓非名實選段／contracts | 名實量規：實測與驗收 | 先登承諾，再拖砝碼使帶慣性的秤桿平衡至少 0.65 秒，形成實測紀錄。數量與交件期限須同時相符，超量或準量逾期也不能直接通過。 |
| 〈髻〉／weave | 記憶經緯：織機操作 | 依每一梭不同的織樣升降五條經線，再引梭往返。閉合織口會擋梭、磨線；三梭會換向及換樣，不是把髮式排成高下。仍屬配合課本的自編導讀。 |
| 〈勞山道士〉紙月幕／paperMoon | 四鏡借月：連續反射 | 移開屏風，拖鏡緣改反射角，追著同一束月光逐面接通四鏡，讓暗案持續受光。任一鏡偏轉、屏風截光或照到空牆都不完成。 |
| 〈赤壁賦〉／riverSong | 江月八拍：音孔與呼吸節拍 | 等音符進入時窗，按對音孔穩吹指定時長；空檔收息，並切換水月觀看尺度。八拍至少接住六拍，持續吹氣與連按都不能代替節拍。 |
| 〈晚遊六橋待月記〉／moonwalk | 六橋光景簿：構圖與曝光 | 拖移取景框，把橋拱及倒影納入不同構圖；拉焦、調曝光、轉時辰盤候光後才按快門。構圖、焦距、光線與曝光須同時相合，膠片有限。 |
| 〈勞山道士〉採樵幕／woodcut | 循紋避結：壓力與手作 | 每片木料改變缺口與木紋角。先移斧落點避結、調斧向，再蓄力 0.6～1.4 秒後放手。偏斧、擊結或蓄力失當會反震耗力。 |

滑鼠或觸控可直接操作場景器物；每款另有專屬按鈕或選擇位置的備用方式。非角色移動玩法隱藏通用方向盤，操作提示隨模式顯示。暫停、失焦或取消觸控會取消未完成的按壓、拖曳，不把取消動作當成落斧、落簡或接線。

## 內容、舊局與計分

- 保留原典與既有 220 題的題幹、選項、答案及解析，不藉改操作重寫首答。
- 保留 83 個劇本路由、59 種模式與 117 幕的既有對應。83 路由包含保留舊進度入口；不代表首頁全部重新列出。
- 八款新核心使用獨立的操作版本，新開或再戰的遊戲紀錄採 `_v4`，與原 `_v3`、`_v2` 及更早紀錄分開。
- 舊存檔不會在讀取時被強制轉成新核心。上述八款的舊局繼續原規則、原操作與原分數；完成後可用「再戰本篇・保留首答」開始新版。
- 十八款直接操作仍使用各原模型的成功、資源與失敗條件；只換輸入方式，不另造較易通關的成績。
- 保留原有首次作答、訂正與首輪／最佳操作的區別，不把教師跳關結果或練習操作列入正式競技。
