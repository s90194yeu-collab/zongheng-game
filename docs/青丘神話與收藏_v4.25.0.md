# 青丘神話與收藏 v4.25.0

本版為《山海異境》的第一區可玩版本。完整企劃中的其他五區、弓手、機巧師、多人合作與班級試煉榜未列入本次發布。

## 入口

- 正式首頁新增「開始神話征討」與「我的收藏博物館」。
- 原收藏頁也能開啟新的收藏展室。原國文劇本、史冊收藏及村莊入口保留。
- 登入、身分與永久保存繼續由 GAS＋Google 試算表處理，不使用 Supabase。

## 本次可玩內容

- 沿用動漫男女角色與外觀，劍士／符師兩種流派。
- 六項屬性共 12 點、八能力選兩項，神話配置與原課程分開。
- 青丘四區段：林間入口、符紋遺跡、石燈庭、狐影環臺。
- 墨團精的分裂、符紙妖的延遲符陣、石甲猿妖的衝撞破甲。
- 九尾狐三階段：辨真身、管理地面危險、引追蹤狐火啟動兩座石燈。
- 12 件獨立收藏；首通取得狐靈卡與狐紋玉墜，普通難度以上累積印記可兌換立像。
- 六個實際 3D 展位，可更換、移除、旋轉與拉近欣賞。
- 靈砂鍛造、燈芯與石甲片配方、收藏缺件線索。
- 引導／標準／進階三種規則，個人最近紀錄。

## 操作

點地面移動、點敵人鎖定普攻；方向鍵或 WASD 也可移動。J 攻擊、空白鍵／K 閃避，1／2／3 或 U／I／O 使用技能，E 互動。

手機左側方向鍵、右側攻擊／三技能／閃避。操作區防止選字與拖圖；拖曳空白處轉鏡頭，雙指或畫面＋／−縮放。可 360 度轉向。引擎未設定 FPS 上限，物理與傷害按固定規則運算。

## 教師試玩

教師開「指引」後可直接選林口、遺跡、石甲猿妖、九尾狐；九尾狐試玩可再跳第二／第三階段。此模式不發正式收藏、材料或紀錄。一般學生與訪客不顯示教師工具。

## 保存

- 訪客：保留在目前分頁的 sessionStorage；關閉分頁或瀏覽器清理後不保證保留。
- 學校帳號：使用新的 MythProfiles 工作表；首次實際保存才建立，不改舊學生資料表。
- 收據與資源置於同一個權威 JSON 儲存格，重送不重複發獎或扣料；每次操作核對修訂。
- 讀取失敗／既有 JSON 損壞時停止寫入，不建立空白檔覆蓋。
- 連線中斷保留待確認請求。明確的規則或版本衝突引導重新讀取。
- 戰鬥與收藏不冒充國文作答或學業成績；本版未開公開競賽榜。

## 問題回報

遊戲內回報預填區段、流派、規則版、保存狀態、裝置與發生時間，並擷取遊戲場景。可修改說明、移除／改附圖片，下載含附件的郵件草稿；純文字郵件另有入口。收件人為 s90194yeu@nssh.ntpc.edu.tw，由使用者確認後自行寄出。

## 美術與原典

十個原創模型由 Blender 腳本建立，採頂點預先明暗、可重用材質與植被實例。角色沿用既有授權素材與動漫改作流程。模型、腳本與 Blender 原始檔另附交付。

九尾狐原型核對《山海經・南山經》。狐火、護盾、燈具、原創小妖與器物是遊戲創作；收藏詳情有分開說明。

## 驗證範圍

發布前執行完整 Node 測試、Godot 真實物理場景測試、原村莊回歸、網站檔案核對與瀏覽器試玩。

瀏覽器實際驗證訪客符師清理林口、取得兩件收藏、擺進展位與重載保留；另驗證教師選區段、首領模型、手機 390×844 排版、方向鍵與技能區無交疊及防選字。此為瀏覽器尺寸預覽，並非實體手機硬體效能測試。

神話規則能核對順序、資料範圍、持有權與重複請求，未宣稱具有競賽級反作弊。實際發布版本、CI、資源雜湊與 GAS 部署核對記錄於交付資料夾。
