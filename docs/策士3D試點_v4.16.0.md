# 我的策士 3D 試點 v4.16.0

2026-10-25。已完成本機驗證並獲授權發布；GitHub、公開資源與正式入口切換結果，以交付資料夾 `../deliverables/策士3D發布_v4.16.0/發布核對記錄.json` 為準。GAS後端維持第60版。

## 可以操作的內容

在「我的策士」頁面點「開啟古風策士試看」，可旋轉、縮放、選擇待機／跑步／行禮、切換六種衣色、暫停、調整畫質及下載角色照片。行禮播放一次後回到待機。

這是原創 Q 版古風策士的固定造型試點。髮型、性別、五官、裝備尚未接到原本紙娃娃的完整造型資料，衣色只保留在這次頁面試看中。返回「我的造型」仍使用既有編輯器。本次預覽不呼叫 GAS，也不改寫配裝、課文、成績或角色同行存檔。

現有遊戲是 Three.js 網頁，這次直接接入網頁。沒有把遊戲遷移到 Godot；沒有使用 Tripo 點數，也沒有建立未核對的 API 端點。Blender 模型與產生腳本可供後續換成 Tripo 或人工精修資產。

## 本機執行

專案原本的 Node.js 22 以上環境即可：

```sh
npm ci
node scripts/build.cjs --no-pin
PORT=4174 npm run preview
```

開啟 `http://127.0.0.1:4174/__preview__/Profile.html`。這是訪客隔離的本機測試頁。

`--no-pin` 保持本地 `gas/GitHubBridge.gs` 的釘選版本。建置只產生本機檔案；正式發布和 GAS 啟用仍需另外執行既有流程。

模型 1.8m 高，14 根骨骼、48 個蒙皮網格、18,688 三角形，沒有外部貼圖或外部 URI。片段名稱固定為 `Idle`、`Run`、`Bow`。衣色只改 `Robe_Main` 與 `Robe_Shade` 材質；皮膚、頭髮、眼睛和配件不跟著換色。後續替換 GLB 時必須維持這些片段／材質名稱與公尺尺度。

模型僅在按下試看後下載。手機自動畫質以 24fps 與最高 1 倍像素比顯示；桌面上限 30fps 與 1.5 倍像素比。離開畫面或隱藏分頁會停止推進動畫，關閉試看會釋放模型、骨架、材質與 WebGL context；減少動態偏好使用靜態姿勢。

## 在 Blender 重建

以下使用 Blender 官方 macOS Apple Silicon 版的命令列程式。若放置位置不同，調整第一段路徑：

```sh
/Applications/Blender.app/Contents/MacOS/Blender \
  --background --factory-startup --python-exit-code 1 \
  --python art/character3d/create_scholar.py -- \
  --output public/models/scholar-pilot.glb \
  --blend art/character3d/scholar-pilot.blend \
  --report qa/character3d-model.json
```

已用官方 `bpy 4.5.3` 實際產生模型及 `.blend`，再用正式 GLTFLoader 解析並檢查骨架、蒙皮與每段動畫。原創程序模型不是 Tripo 生成結果，也不是完整商業級動漫角色。

## 常見問題

- **雙擊 HTML 後沒有模型**：ES module 與 GLB 需要 HTTP 伺服器，請使用上述 `npm run preview`；下載包內另附獨立預覽啟動檔。
- **一直載入或模型檔 404**：重新建置，確認部署包含 manifest 指定的 `assets/character3d-app-*.js`、`assets/three-r180.min.js` 與 `models/scholar-pilot-*.glb`。本地 `public/models/` 會保留舊雜湊，供舊 release 使用。
- **畫面中斷／無法開啟立體試看**：按「重新載入角色」，或返回「我的造型」；檢查瀏覽器 WebGL 是否可用。
- **動作沒有播放**：檢查是否按了暫停，或系統開啟「減少動態」。跑步是原地動畫，不會移動遊戲角色。
- **手機較慢**：畫質改「流暢」；這版尚未合併網格，目前約 50 次主畫面繪製呼叫，仍有後續優化空間。
- **新衣色沒有存到帳號**：這版是固定模型預覽，尚未接完整造型儲存。請使用原換裝介面保存正式角色。
