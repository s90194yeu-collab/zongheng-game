# 劇情競技改造 v4.4.0

使用者指出先秦諸子以後的關卡欠缺競爭，文本也偏向講義。本次重做35關、97幕：先秦諸子12關、古文十五篇新增11關、A類選文新增12關。春秋、戰國、楚漢40話與共用關卡的ID保留。

## 劇情與文本

每幕有獨立場景敘事、人物對話、場地與對手。沿用現有AI場景並按幕切換，採角色立繪、旁白、逐句推進與紙卷對話框。原典另有「原文對讀」，改編台詞明示「教學改編對話」。戰後用人物問對接回課文，176題原文、題幹、選項、答案及解析與改造前逐字相同。髻、散戲仍為自編導讀，配合課本閱讀。

每場先選戰術，實際改變體力、速度、出手力量、氣力或判定範圍。對話、戰術與局中狀態都可存讀；操作即時開始，背景存檔不會卡住方向鍵。

## 四種競技

|玩法|操作與競爭|失敗條件|
|---|---|---|
|攻防對決|讀取蓄力範圍，閃避衝鋒、震波及散射，趁破綻反擊；三階段攻勢|體力耗盡或時間到|
|雙人競速|可見對手沿路線競跑，順序通過12處路標，兩圈爭先；衝刺、牽制及障礙|對手先到、體力耗盡或時間到|
|多線守備|奔走三路、擊退不同敵人、有限物資回防修復|玩家倒下、防線崩潰或結束時防線過低|
|節奏競演|上下走位對準三線，在時間窗合拍、累積連段，與對手聲勢比較|命中率不足或聲勢未超過對手|

練習模式放慢攻勢並增加容錯，仍須親自操作；不列競技榜。新版遊戲代碼加_v2，與舊蒐集玩法分開排行。不同篇章有不同對手、幕間玩法與路線／波次／節拍變體。

## 舊存檔

舊局中世界仍使用原模型完成；新開與重玩採新版。保留首次作答、訂正、首次操作及最佳操作；重試不覆寫首輪。已通關者可按「再戰本篇・保留首答」，體驗新版。舊新紀錄同時存在時，每幕只計一場，避免分數重複加總。學校登入及資料仍由原GAS與Google試算表處理。
