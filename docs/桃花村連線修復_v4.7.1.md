# 桃花村教師試玩離開後的連線恢復 v4.7.1

使用者回報部分篇章出現「本章暫時無法開啟／NetworkError：HTTP 0」，具體發生在〈花和尚大鬧桃花村〉離開教師測試時。正式入口依相同步驟重測，當次能正常讀回原存檔，因此沒有把間歇性連線問題宣稱為固定的桃花村劇本錯誤，也沒有證據判定為特定網路或Google服務故障。

原共用呼叫遇一次連線失敗便中止；章節的「重新讀取文本與進度」只重跑原框架的資料請求。本次補強兩條恢復路徑，維持原登入、題庫與存檔權限。

- 僅對七個明列的讀取API，在NetworkError、HTTP 0等傳輸失敗時重試，總共最多三次，間隔700與1800毫秒。既有30秒逾時仍直接結束，不自動累積至90秒。畫面顯示重試次數。
- 存檔、首答紀錄、通關、技能及未知API不自動重送，避免重複寫入。權限、題目停用、格式錯誤沿用原結果，不以重試或空白資料取代。
- 仍無法讀取時，畫面指出正在讀取存檔、題庫或帳號資料；保留原地重試，新增原生「重新連線本章」連結。連結以最外層正式入口重開本章，保留模式與教師測試參數，不重載空白的內層iframe。
- 章節讀取期間阻擋重複啟動；存檔與題庫未完整成功前不建立可玩的空白局，也不寫入存檔。
- localhost限定的測試工具增加短暫失敗、重試後恢復、重開整頁後恢復三種故障情境；正式畫面不載入此測試工具。

驗證：本機95項通過；獨立公開副本90項通過、5項私有後端檢查略過，私有5項已在本機通過。新增七項針對測試，涵蓋三次上限、讀取參數保留、正式首答讀回、寫入不重送、逾時與晚回應、題目停用、重複點擊及整頁連線參數。瀏覽器實際操作已驗證HTTP 0後原地重試可恢復，以及原生重新連線能重建整頁並開啟桃花村。沒有宣稱能修復持續斷網或由外部網路阻擋的連線。

畫面版本：`v4-46fe14035f6ee3`，介面版本`v0.3.9`，83路由、89頁、224素材及7首配樂保留。此次更新共用前端，GAS正式後端仍沿用第52版與原Google試算表，不建立第53版，不清除任何存檔。

實作在`Core_js.html`、`Zhuzi_js.html`；回歸測試為`tests/network-recovery.test.cjs`。交付驗證與實際發布結果保存於`../deliverables/桃花村連線修復_v4.7.1/`。

API行為參照[Google官方說明：與伺服器函式通訊](https://developers.google.com/apps-script/guides/html/communication)及[google.script.run參考](https://developers.google.com/apps-script/guides/html/reference/run)。
