# 原創角色與三套換裝 4.22.0

「我的策士」加入可選的古風半寫實男策士。玩家能在個人頁預覽與儲存，進入博物館村後使用同一套人物、衣裝、膚色、髮色和衣色。

## 使用方式

1. 在「我的策士」選「古風半寫實・男策士」，搭配書院服、行旅服或輕甲；也可從上方「古風策士試看」切換衣裝與動作。
2. 在原編輯器調整四種膚色、六種髮色與八種衣色，儲存策士資料；試看區的「套用這套造型」也沿用同一個儲存流程。
3. 回到關卡首頁，打開博物館村。一般移動播放走路，Shift 奔跑播放跑步；360 度旋轉與縮放沿用原操作。
4. 切回「經典紙娃娃」即可恢復原有完整服裝、髮型與配件。原本的其他設定保留，不因試看而清除。

此款首版固定成年男策士、束髮與玉簪。2D 頭像、舊收藏館的紙娃娃及既有劇本的圖像呈現沿用原造型；新模型用於個人頁和博物館村。角色能力、技能、課文走向與存檔規則未改動。

## 模型與性能

53 骨共用骨架，四段動作：待機、走路、跑步、行禮。三套衣裝共用人物，僅選中衣裝會繪製。

| 執行檔 | 大小 | 書院服可見三角面 | 行旅服 | 輕甲 |
|---|---:|---:|---:|---:|
| 精緻版 | 6,553,948 bytes | 36,940 | 38,210 | 44,080 |
| 輕量版 | 1,985,740 bytes | 22,544 | 23,091 | 26,588 |

個人頁依初始畫質與裝置寬度選擇模型；切換畫質會重新載入對應模型。村莊使用輕量版。保留人物 PBR 材質，既有經典人物仍沿用原渲染方式。沒有加入 FPS 上限，動畫與移動仍依經過時間計算；頁面隱藏及關閉時停止繪製並釋放資源。

## 保存與相容性

外觀增加 `characterStyle`，選項 `classic`／`hero`，預設 `classic`。沿用既有 `PlayerAppearance` JSON 欄位與修訂版本檢查；沒有新增學生資料庫，也不需要建立新工作表。GAS 的既有集中設定驗證直接讀取更新的 `Data_doll3d`，ProfileApi 程式不需改動。

正式更新只更換 `GitHubBridge` 與 `Data_doll3d`，其餘 GAS 來源原封保留。建置及模型測試不寫入真實學生紀錄；儲存流程以本機訪客驗證。

## 驗證

本機 290 項測試通過，包含舊關卡與後臺相容性、模型資料有效性、權重正規化、換裝可見性、動作循環、真正蒙皮頂點變化、手機模型縮減，以及 GAS 讀取舊造型、新樣式與拒絕不支援的欄位。

瀏覽器另測個人頁、試看、換裝、四段動作、暫停、鏡頭旋轉縮放、訪客儲存與重新載入，以及手機排版和村莊接入。證據保留在 `qa/原創角色_*.png` 與 `qa/hero-browser.json`。

AI 設定圖使用內建 ImageGen；詳細提示詞和可編輯 Blender 來源在 `art/hero/`。實際模型仍可持續細修髮絲、衣褶與甲片輪廓。
