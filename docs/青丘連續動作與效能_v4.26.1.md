# 青丘連續動作與效能 4.26.1

## 動作與視角

原角色每方向只有兩格走路、一格攻擊，走位也直接跟隨60Hz物理位置。本版換成兩套原創角色各96格：八方向，每方向六格走路與六格攻擊。圖像由ChatGPT內建imagegen重新生成，PNG原圖不經程式重繪；圖集、完整提示詞與透明輪廓校準程式在 `art/hd2d-motion/`。

使用遊戲動畫圖集連續播放，類似GIF逐格動作的概念，可保留遊戲自己的移動、方向、出招與命中控制。轉鏡頭時保留目前動作進度，加入方向邊界防抖；每格以臀部與腳底校準，避免圍巾、手臂改變裁切範圍時整個角色橫跳。攝影機與人物視覺使用物理插補，碰撞、尋路及敵人AI仍按原60Hz執行，不鎖繪圖FPS。

普通攻擊先預備，再於圖格的命中段結算；閃避可取消尚未命中的攻擊。劍士／符師、技能、狐王破盾、課程成績與收藏規則保留。

## 效能

- Blender將山門、溪橋、樹冠、遺跡依材質合併；原始未合併 `.blend` 保留。四件模型共98個獨立網格改為11個，預先頂點陰影與UV仍在。
- 共用場景材質與著色器，移除重複溪橋裝飾；重玩可重用已載入的靜態林地，保留新一局敵人、拾取物與戰果重設。
- 進場與換角時先預載動作貼圖；引擎標準貼圖壓縮及縮圖層降低下載量與遠看閃爍。
- 高解析度螢幕與持續慢幀自動調節3D解析度，介面文字維持原解析度；沒有30／60 FPS的人為上限。

本機M4、1280×720、Godot Compatibility的固定走位旋轉樣本：繪圖呼叫中位數118降至85（約28%）；場景獨立網格342降至208。原生中位幀時間前後約7ms，不能據此宣稱所有裝置的FPS提高。原生樣本仍各有一次超過33ms的停頓，未宣稱完全消除所有卡頓。瀏覽器與實體手機表現可能不同。

本版首次傳輸約32.6MB，上一版約26.4MB，主要增加八方向動作素材；已採引擎壓縮，沒有拿下載時間當作遊玩FPS。

## 核對

24項動作／視角／命中／重玩／解析度調節測試通過；原戰鬥27項與原博物館村場景通過。Node315項中308通過、7項因未附私有GAS來源略過、0失敗；90章、96頁、231件素材核對通過。手機為瀏覽器尺寸預覽，不代表實體手機效能量測。

登入、雲端保存與學生資料仍為原GAS＋Google試算表；不變更學生欄位或遷移資料。後端只需更新GitHubBridge，舊版保留。

## 原稿

- `art/hd2d-motion/raw/`、`prompts.json`、`analyze_atlases.py`：原圖、完整提示詞與只讀透明輪廓分析。
- `art/hd2d-motion/batch_scenery.py`、`tree-batched.blend`：Blender合併作業與樹冠可編輯稿；完整未合併場景仍在 `art/hd2d/qingqiu-hd2d-scenery.blend`。
- `godot/village/hd2d_actor.gd`、`myth.gd`、`test_motion.gd`、`benchmark_motion.gd`：可編輯遊戲及回歸／量測工具；測試工具不包含在網頁遊戲封包。
- `godot/village/assets/hd2d-motion/*.png.import`：需保留的引擎貼圖匯入設定；`.godot/`是可重建快取。
