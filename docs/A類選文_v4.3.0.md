依使用者提供的龍騰《ABC選文表-108、109適用》整理；A表示4～5家出版社選用，不代表難度或現行所有教材的共同分類。詩、詞、曲、賦暫不加入，依指定保留〈漁父〉。共26篇，十四篇沿用原ID與存檔，十二篇新增獨立任務。

沿用既有遊戲與原文閱讀入口，不重複登記章節、不另建存檔。表中洪棄生即既有課文作者洪繻。原「古文十五篇」仍保留〈赤壁賦〉，只在本次A類篩選中排除。

## 美術、資料與驗證

新增三張內建 image_gen 生成的AI場景：街市酒店、臺灣戲臺後場、家屋梳妝室；其餘沿用適合情境的既有AI背景。插畫是教學情境想像，非史料或實景照片。原圖及完整提示詞保存在工作區交付資料夾，不上傳學生資料或私有備份。

全站75關、81頁、216件圖片與字型素材。登入、學生資料與存檔仍由原GAS及Google試算表處理，不使用Supabase。正式更新保留既有部署版本及網址。

本機28項測試通過，含篩選清單、十四篇ID共用、題庫停用、首答訂正、收藏分母、變動段數計分，以及舊頁面和私有後端相容性。已實玩〈漁父〉三段六題、〈吾十有五而志於學〉答錯→重新整理→訂正→單段結算；390×844手機方向盤完成〈顏淵問仁〉短章。正式新章另逐一核對啟動，僅讀取學校進度與題庫，不在正式帳號提交作答。

程式來源為 `src/content/a-selections.cjs`、`a-texts.json` 與 `scripts/generate-a-selections.cjs`。交付資料在工作區 `deliverables/A類選文_v4.3.0/`，含清單、審閱用題目、提示詞與驗證紀錄。教師後臺測試仍依使用者指示暫緩。
