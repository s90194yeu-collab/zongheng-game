# Godot 村莊試點 4.24.0

首頁新增「Godot 村莊體驗」。可操縱動漫男角或女角，在暖色水彩書院走動、奔跑、跳躍，旋轉與縮放鏡頭，沿光點到六館，進館讀導讀並選擇課程。

原村莊仍可使用；體驗版上方有「使用原村莊」供比較。

## 如何試玩

1. 在首頁按「Godot 村莊體驗」。首次需下載約 48 MB 的引擎與場景檔，載入畫面有進度及重試。實際傳輸量取決於網站壓縮與瀏覽器快取。
2. 可先找書僮取得指引，或點六館按鈕帶路。靠近館門後按互動進館。
3. 點「走向主展櫃」或自行走到展櫃，按互動即可看各館導讀與挑選課文。原本需學校登入的課程，仍需登入。
4. 「角色換裝」提供男角、女角、三套服裝及八種衣色。按「儲存這套造型」沿用原 GAS 外觀存檔。首次使用需先在我的策士完成命名規則設定；訪客僅保存在本分頁。

## 操作

點地面走動；拖曳旋轉；滾輪或雙指縮放。也可使用方向鍵／WASD、Shift 奔跑、空白鍵跳躍、E 互動。手機有方向、奔跑、跳躍與鏡頭按鈕，操作區避免長按選字。

場景採真正 Godot 角色物理、碰撞與尋路。牆、館舍及庭園不可直接穿越；進館後切換室內場景。鏡頭可旋轉 360 度，背牆依視角剖開以利觀展。沒有設定 FPS 上限。

## 保存與範圍

登入、學生資料、課文進度與學習診斷沿用 GAS＋Google 試算表。Godot 不接收學生身分；選課與保存外觀都交回原網頁驗證，逛館不會冒充課文完成紀錄。

這次是 Godot 村莊試點，課程按鈕會進入原有完整課文遊戲。〈燭之武退秦師〉的夜縋潛行仍為原版，尚未移植為 Godot 關卡。

## 可編輯專案與驗證

Godot 專案在 `godot/village/project.godot`。角色與場景沿用現有 GLB，保存三套衣裝與待機、走路、跑步、行禮四段動畫。

301 項 Node 本機測試通過；另用真正 Godot 場景核對骨架動作、女角換裝、路徑可行、人物實際抵達館門與展櫃、進出館、跳躍及暫停。瀏覽器的電腦與手機尺寸操作證據保存在 `qa/Godot*`；尺寸模擬不等於實體 iPhone／Safari 驗證。
