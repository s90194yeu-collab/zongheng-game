# 3D博物館村 v4.17.0（第一版）

原首頁保留清單，另加「走進3D博物館村」入口。策士可用WASD／方向鍵、手機方向按鈕或點擊地面移動；選「展館導覽」可沿路走到館門，再按E或互動按鈕進館。展廳走近展櫃後開啟本館篇章。

六館依現有有效目錄分為春秋18、戰國13、楚漢9、諸子13、古文11及選文22，共86篇。排除4條舊存檔路由。正式整合讀取ZH.CATALOG並用ZH.canPlay決定權限，選擇後交回Hub既有openScenario，因此學號、訪客權限、已通關再挑戰與原存檔規則仍由原流程處理。

## 本機預覽

```sh
node scripts/build.cjs --no-pin
PORT=4178 npm run preview
```

開啟http://127.0.0.1:4178/__preview__/Hub.html，點村莊入口。--no-pin保留gas/GitHubBridge.gs既有釘選。本版依使用者授權發布GitHub Pages，並透過僅一次的固定版本遷移切換已啟用的正式入口；來源、權限與舊版回復規則維持。發布與核對結果見交付紀錄。

## 來源與資產

- src/legacy/Hub.html：入口與選章事件，沿用原openScenario。
- src/legacy/Village_boot.html：延後載入、全螢幕dialog與關閉／重試流程。
- src/village/app.js：3D場景、角色動作、移動、進館、展櫃、手機控制及資源釋放。
- src/village/world.js：六館布局、碰撞、A*尋路及展館目錄篩選。
- src/village/style.css：村莊與展櫃介面。
- public/models/museum-village.glb、museum-interior.glb：外景與共用展廳；建置以內容雜湊保存並保留舊模型。
- public/models/scholar-pilot.glb：沿用前版固定Q版策士。
- art/village/：Blender原始檔、create_village.py建模腳本與prepare_generated_asset.py整理腳本。

外景19個材質網格、79,528三角形、約5.1MiB；共用展廳13網格、3,812三角形；角色14骨骼、18,688三角形。主畫面約67次繪製呼叫。共用既有Three.js r180，不新增後端API或資料表。角色目前只讀取既有衣色，完整造型尚未接入。離開頁面後村莊位置重置，離館會回原館門口。

## Tripo與美術範圍

此次資產由Blender程序建立，不是Tripo生成。官方Tripo CLI0.7.3已在本次Codex任務工具資料夾安裝，兩份dry-run通過，尚未登入；未驗證餘額／生成結果，也未提交付費任務。

下一階段先精修一棟代表館與一位主角，確認風格和費用後再擴展。現有六館共用室內布局，文物、NPC、獨立展陳與完整換裝待製作。外景目前合併一個GLB，單館Tripo模型不能直接覆蓋整村，須先拆分或重組場景。API新接線以官方v3文件為準；先前v2範例不作新流程基礎。
