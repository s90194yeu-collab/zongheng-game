# 安裝與更新（GitHub＋Google 雲端版）

不需要建立 Supabase 帳號，也不需要重新搬移學生資料。

**本次專案已由程式完成 GAS 三檔同步，並把原網址由第 44 版更新至第 45 版；網址與存取設定保持不變。你現在可跳過第二節的貼檔和第三節的更新部署，只需完成 GitHub Pages 設定，再執行安裝函式。以下保留完整流程供日後重裝使用。**

## 一、讓 GitHub 發布遊戲檔案

儲存庫：<https://github.com/s90194yeu-collab/zongheng-game>

1. 點 **Settings（設定）**。
2. 左側點 **Pages（網站發布）**。
3. 在 **Build and deployment（建置與部署）** 中，將 **Source（來源）** 設為 **GitHub Actions（自動發布工作流程）**。
4. 回到 **Actions（工作流程）**，開啟「發布縱橫鼎業」。綠色勾號表示完成；若尚未執行，可點 **Run workflow（執行工作流程）**。
5. 開啟 <https://s90194yeu-collab.github.io/zongheng-game/>。看到入口畫面表示 GitHub 已就緒；此時先不要用入口判定新遊戲已啟用。

## 二、第一次只更新 GAS 共用入口與必要資料

原有的學生資料、試算表與 Apps Script 專案繼續使用。

1. 在原 Apps Script 專案找到 `Code.gs`（大小寫可能顯示為 `code.gs`），以本包 `gas/Code.gs` **完整替換同一個檔案**；不可再新增第二份 Code。
2. 按 **＋ → 指令碼**，新增 `GitHubBridge`，貼上 `gas/GitHubBridge.gs` 全文。
3. 本包包含目前最新的 `gas/S_cq13_zichan_data.gs`。若先前 v3.0.0 尚未同步，請完整替換 GAS 同名資料檔；若已同步則不必重貼。
4. 保留原本的 Auth、Save、Log、TeacherApi、ProfileApi、ProgressApi、其他資料檔與 HTML。這些提供原有登入、權限、存檔與故障回復。

這個步驟不必把 40 話 HTML 全部貼回 GAS。最新的 40 話畫面由 GitHub 提供。

## 三、安裝並更新原網頁部署

1. 在 Apps Script 左側點開 `GitHubBridge` 檔案，再從上方的函式選單選 `installGitHubFrontend`。
2. 按 **執行**。若 Google 提示授權，完成同一個專案的授權。
3. 程式會先確認全部 46 個頁面可讀且內容正確，再切換至新版。成功紀錄應有 `ok: true`、`enabled: true`、`chapters: 40`、`pages: 46`、`media: 202`、`music: 7`。
4. 按右上角 **部署 → 管理部署作業**，選原本的網頁應用程式，點鉛筆圖示。
5. **版本** 選 **新版本**，按 **部署**。沿用原本的執行身分與存取設定、沿用原網址。
6. 重新開啟原遊戲網址。手機與電腦都可沿用，不必換學生登入帳號。

若顯示 GitHub 404，先確認第一節的發布已完成，再執行安裝。安裝未完成時，程式不會把半成品設為啟用。

## 四、上線驗收

本機已驗證全部 40 話能啟動、圖片不再呼叫 GAS，以及首頁與紙娃娃畫面。下列使用真實帳號與試算表的檢查，需在部署完成後進行：

- 用學校帳號登入，確認自己的原有名稱、收藏和進度。
- 在一話中保存，再重新進入，確認進度可接續。
- 通關後於同一分頁結算，確認紀錄寫入原試算表。
- 使用教師帳號開啟後臺，確認名冊、名稱管理鎖定及成績。
- 開啟個人頁與 3D 收藏館，確認換裝、動作與配樂。
- 用訪客模式確認只開放原本設定的課綱四關。

GAS 仍需要處理登入及資料讀寫，所以存檔回應仍可能需要等待；較大的圖片、音樂與共用程式已改由 GitHub 直接提供。

## 五、之後更新

1. 更新本專案，推送 GitHub，等「發布縱橫鼎業」成功。
2. 在原 GAS 編輯器再執行一次 `installGitHubFrontend`，切換到已驗證的新版本。
3. 更新畫面與素材不必逐話重貼。若有新增 API、修改題庫或資料欄位，另外同步對應的 `.gs` 檔。

已發布的畫面空殼與共用檔會保留於 `public/releases/`、`public/assets/`，方便版本切換期間繼續使用。請不要隨意清除這兩個資料夾。

## 六、回復原版

在 GAS 編輯器執行 `disableGitHubFrontend`，重新載入遊戲即沿用原 GAS HTML。此操作不刪任何學生紀錄。

若單次讀取 GitHub 畫面失敗，入口也會嘗試回原 GAS HTML。已開啟的畫面若遇到網路或素材錯誤，仍需重新整理。

## 檔案位置

| 位置 | 用途 |
|---|---|
| `src/legacy/*.html` | 全部劇本、平台畫面、引擎與 UI |
| `src/legacy/*_data.gs` | 供建置使用的集中劇本資料，不含學生紀錄 |
| `public/media/` | 202 件素材 |
| `public/music/` | 7 首配樂 |
| `public/assets/`、`public/releases/` | 已發布的共用檔與畫面空殼 |
| `gas/` | 原 GAS 專案需要的共用入口、橋接檔與必要資料更新 |
| `scripts/` | 建置、本機預覽與檢查工具 |
| `qa/` | 本機驗證結果；沒有真實學生帳號資料 |

不要把試算表匯出資料、OAuth 憑證、教師密碼或同步工具憑證放進這個公開儲存庫。現有資料維持原本 Google 分享權限。
