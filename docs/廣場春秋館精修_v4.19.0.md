# 中央廣場與春秋史館精修 v4.19.0

本次將中央廣場與春秋史館建為可在原網頁遊戲中行走、進館、近看展品的 Blender 示範。其他五館保留原有建築輪廓與共用展廳，沒有宣稱六館均已獨立重製。

## 美術與互動

- 廣場：青銅鼎、石座鑲圈、鋪石邊界、荷葉與水紋、竹叢、遠景山形及木石貼圖。春秋館細化柱礎、梁架、窗櫺、門板、瓦脊與簷下椽木。
- 春秋館使用獨立展廳，加入石磚、欄杆、竹簡架、格窗、懸卷與三件不同的展品。左右展櫃與主展櫃位置保持一致，沿用原碰撞與導航。
- 從春秋展櫃三種導讀切換「近看青銅禮器／盟書竹簡／列國沙盤」，可拖曳旋轉、縮放、重設視角及選擇三個觀察部位。竹簡六個活動分組可收攏與展開。
- 文物近看使用已載入的春秋館網格，不再下載第二份模型。近看時暫停村莊的行走及繪製；關閉時清理檢視器與控制器，不釋放共用的展館貼圖／幾何。返回篇章仍交由原 onSelect／openScenario 檢查權限。
- 書僮會朝向角色，靠近時有輕微點頭；降低動態偏好下停止該動態及竹簡過渡。

## 原始檔與重製

原始 Blender 4.5.3 LTS 幾何及自製程序繪製貼圖保存在 `art/village/refined/`。產生器會建立內嵌 PNG 的 GLB 及打包貼圖的 `.blend`，沒有使用第三方圖像、付費生成或 Tripo。

```sh
blender --background --factory-startup --python-exit-code 1 \
  --python art/village/refined/create_refined.py -- --output /tmp/refined-assets --render
```

`museum-village.blend` 與 `spring-interior.blend` 是本版原始檔；上一版 `art/village/museum-village.blend` 留作歷史來源。執行器不隨專案散布。`refined-report.json` 記錄三角形、大小與實際嵌入貼圖數；公開網頁只用 GLB。教學器形、竹簡墨痕與列國沙盤均為美術／推理示意，並非出土文物掃描、精確疆界或原文轉錄。

## 網頁負擔與驗證

- 每個場景 GLB 小於 8 MiB；貼圖不超過 512×512 且無外部網址。模型與程式使用內容雜湊檔名，舊發布資源保留。
- 展品近看最高桌面30／窄螢幕24次繪製每秒，像素倍率上限1.5；村莊沿用手機品質模式。檔案載入可取消，逾時45秒會回到可重試的錯誤畫面。
- 新測試覆蓋 GLB／PNG 封裝、模型分組與位置、各展品文字、只限春秋館開啟、近看反覆關閉釋放、失敗後仍可返回，以及模態畫面暫停移動。
- 桌面 Chrome 本機已實際操作三件展品、竹簡收攏／展開、部位切換與縮放，並由展櫃返回燭之武原入口。iPhone16 393×852為瀏覽器尺寸模擬，未宣稱實體手機或學校本人帳號驗收。開發者工具僅見本機 favicon 404，未見程式例外。
- 最終測試、GitHub／GAS版本與正式入口核對以 `../deliverables/廣場春秋館精修_v4.19.0/發布核對記錄.json` 為準。只更新 GitHubBridge 以切換固定前端版本，其餘學生資料、存檔與 ArchiveData 設定保持原狀。
