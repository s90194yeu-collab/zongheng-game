# 不鎖 FPS 與美術提案 v4.19.1

依使用者要求，村莊、文物近看及策士3D試看均移除原本桌面30／窄螢幕24fps的程式限制。每次 requestAnimationFrame 回呼都可繪製，實際更新率由瀏覽器、螢幕與裝置狀態決定，不宣稱固定達到60／120／144fps。WebGL powerPreference 改為 default，交由瀏覽器選擇。

保留以經過時間計算角色移動與動畫；長時間離開後的時間差限制用於避免角色穿牆，並非 FPS 上限。頁面隱藏、離開視窗、模型釋放與失去圖形內容時，原保護仍保留。村莊館牌投影改用 ResizeObserver 更新的尺寸，避免逐一寫入館牌位置時重複讀取版面。

新增測試用實際動畫迴圈回放60／120／144Hz回呼，核對三個視圖沒有丟棄回呼；另核對30／60／120／144Hz下每秒移動距離及策士動畫時間一致，並驗證隱藏與釋放後不繪製。這是自動化時間回放，與實際裝置幀率量測分開。

五款美術範例為內建 imagegen 生成的概念圖，保存在本機交付資料夾「不鎖FPS與五款美術提案_v4.19.1／五款美術範例」，含原圖、提示詞與編號比較頁。風格待使用者選定後才製作正式2.5D場景。角色與近看文物維持真正3D；後續建築、庭園與遠山以分層美術和簡化結構製作，光影盡量預先烘焙。本次沒有把概念圖直接當作已完成的可行走場景。

本機274項測試通過。原GAS登入、學生資料、原篇作答、存檔及ArchiveData模式不改動；正式版本切換僅更新GitHubBridge。發布與驗證結果見交付「發布核對記錄.json」。
