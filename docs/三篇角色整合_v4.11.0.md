## 章內循環與差異玩法

原文證據（2題）→專屬挑戰→課文反思（2題）→依錯題概念安排不同短補救題→個人紀錄。共12道主要判斷、8道補救；每題須選判斷及支持原文。閱讀不計操作時間，能力不替代回答。首次誤解、訂正與補救歷程分存；操作通過後先停在反思，全部必要閱讀完成才記整章完成。

- 燭之武：巡燈迂迴、近壁守穩、中庭搶隙三條實際路線，暗龕位置、速度、握力耗損、暴露代價或限時不同。可繞道拾封印，另挑戰低暴露及保留握力。
- 大同：鄉里四日與倉雨調序，需求先後不同；按兩項人物專長銜接養老、育幼、照護、勞作、公共倉。選做目標為四日都按專長輪值、總調動不超過14次。
- 諫逐客：三段底本展讀、四處訛字與三段論證作用；選做目標為校字無誤改、論證標籤首次皆正確。訛字明示為自編教學材料。

每篇依自己的操作數據提出方向，和文本理解分列。學習工坊的「學習診斷」也可讀本人角色run、顯示分項資料並進入章內續玩或補救，再返回工坊。原篇首答仍在原診斷區，沒有把角色訂正灌入原首答或學習五維。
