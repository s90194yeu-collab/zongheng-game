# 手機操作與360度視角

共用操作按鍵與其文字、遊戲畫布停用長按選字及系統長按選單；保留閱讀文字、輸入欄位與回報表單的選取功能。按鍵仍沿用原本 pointer capture、放開與取消的清理方式。

村莊與六館室內共用可環繞360度的鏡頭。點一下地面走路、拖曳旋轉、滾輪或雙指捏合縮放；也可使用＋／－、左右轉與重設按鈕。方向鍵改依目前視角行走。轉動、捏合、取消、失去擷取與操作遮罩都不會誤觸地面尋路。預設縮放較靠近角色，俯瞰保留全村範圍。

六館外景以 Blender 建立四面立體牆體、山牆、屋頂、樹木和環繞遠景，使用暖色繪本配色與紙感貼圖；水彩草地、鋪面與池塘沿用既有素材。建築不再是朝單一鏡頭的圖層。建築明暗烘焙於頂點色，不增加即時陰影貼圖。館內從背面觀看時自動剖開背牆上半部，展櫃、文物與碰撞保留。

`art/orbit/create_orbit.py` 為 Blender 4.5 重建程式，沿用既有原創教學建模函式；`orbit-village.blend` 包含可編輯幾何與內嵌貼圖，`orbit-report.json` 記錄大小與幾何數量。現場建築是教學情境重建，並非古蹟掃描。

284項本機測試通過，含完整角度回轉、視角相對移動、手勢與單擊分流、雙指縮放、取消清理、共用防選字、館內剖牆與六館立體深度。本機瀏覽器實測村莊拖曳／按鈕旋轉、縮放、帶路入館與春秋館後方視角；390×844手機版面長按方向鍵未出現選取文字，縮放與旋轉按鈕均至少44像素。這是瀏覽器尺寸模擬，未宣稱實體iPhone或硬體FPS量測。

GAS與Google試算表繼續處理登入與學習資料。本次只更新前端橋接，沒有新增或修改學生成績。
