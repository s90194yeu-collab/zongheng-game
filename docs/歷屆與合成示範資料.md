# 歷屆與合成示範資料

`ArchiveData.gs` 管理教師分析的資料範圍。這次匯入的國文增廣90人為程式生成資料，不能稱作學長姐或歷屆學生的實測紀錄；未來若有合法取得的歷屆實測資料，應以不同批次及正確來源另行匯入。

本批為同一批90位匿名代碼 `nss001`～`nss090`，各開始〈燭之武退秦師〉與〈馮諼客孟嘗君〉。代碼沒有電子郵件，也不建立登入帳號。紀錄保存在原資料庫的八張 `SIM_` 工作表，每筆保留 `isSimulated`、`simulationBatchId`、`cohort`，不搬入正式學生紀錄。合成日期為2026年10月20日至25日。

原部署教師可從 Apps Script 函式選單執行：

- `archiveUseRealDataOnly`：只統計真實學生；也是未設定時的預設模式。
- `archiveIncludeSyntheticDemo`：教師唯讀分析合併90位示範資料，總覽的資料時間旁顯示來源說明。
- `archiveCheckDataMode`：查看目前模式。

執行後，在教師後臺按「重新整理資料」。每次詳情與反思查詢沿用畫面當時的資料範圍，避免切換期間混讀。示範學生不提供帳號管理操作。合併檢視可下載附來源欄位的 `DEMO_` CSV；正式成績匯出維持真實資料，合併畫面會要求改下載CSV。學生首頁、排行榜及五維同步不受這個開關影響。

這兩課沒有文辭遊戲，文辭維持沒有資料。合成反思僅為系統呈現測試，不能當成學生原話或研究證據。
