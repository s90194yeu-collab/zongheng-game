# 博物館村：指引、提示與互動 v4.18.0

首次進村提供可略過的四步小卡：找館、入館、觀展、選課。「自由探索」只收起指引；「遊玩指引」可隨時重開。所有導覽狀態只存在當次記憶體，不寫入學習紀錄或後臺。

六館館牌可點選，小地圖顯示角色位置並提供六館帶路；館牌與地圖皆可用鍵盤操作。目的地有地面光點、方向標記、距離與停止帶路按鈕。抵達後改顯示入館提示，不自動替玩家進課。方向鍵接管、取消、開啟說明與離館時會一起清除舊路徑與提示。

廣場增加引路書僮，可重新查看操作說明或請他挑選目前帳號可進入的課。推薦清單與點擊當下都重新核對權限；沒有可玩篇章時允許繼續逛展。進課仍交回原本 openScenario，沿用原存檔、學號、教師試玩與訪客規則。

館內三個展櫃各有不同導讀與探索問題，並可切換人物、情境與原文視角；完整篇章清單仍保留。文字為閱讀引子，不冒充課文原句，不代答或新增課文成績。

畫面沿用原有GLB，新增程序式書僮與可共用的路徑幾何；不增加遠端資產服務。手機提供可折疊小地圖與方向鈕，避免遮住互動區；減少動態模式停用路標浮動。新功能延後至開啟村莊才載入。

本版修正說明視窗中世界鍵盤誤動作、帶路停止後公告殘留、觸控取消後誤觸路徑等情況。發布保留原Google資料與後端，GAS只調整固定版本接線；公開資源核對通過後才切換正式入口。
