# 問鼎書院：暖色水彩繪本 2.5D

依使用者選定的第 2 款風格，村莊外景改用原創 AI 水彩素材與 Blender 分層平面。六館、竹林、櫻樹、園石、蓮池和三層遠山，分別放在可行走世界的不同位置；鏡頭維持固定方向並跟隨角色平移。村莊入口、帶路、展館與篇章權限沿用原有流程。

角色與廣場銅鼎保留真正 3D；館內與可旋轉、縮放、展開的近看文物沿用原 3D 模型。本次美術範圍為村莊外景。

建築與庭園的明暗預先畫入貼圖，以不受即時燈光影響的材質呈現；全村不產生即時陰影貼圖。角色與文物仍以燈光呈現體積，角色腳下採共用小型接觸陰影。保留逐幀 requestAnimationFrame，沒有 24、30、60 FPS 上限；實際更新率由瀏覽器、螢幕與裝置狀況決定。

## 素材與重建

- `art/watercolor/watercolor-village.blend`：Blender 4.5.3 LTS，貼圖已內嵌。
- `art/watercolor/create_watercolor.py`：依 `layout.json` 重建地面、帶路石徑、六館、庭園與遠山；原始 PNG 依 `prompts.json` 的 id 命名。
- `art/watercolor/watercolor-report.json`：25 個網格、1,046 個三角形、10 張內嵌貼圖，GLB 約 6.05 MiB。
- 原始 AI PNG 保留於交付資料夾的「AI原圖」，不修改原圖；遊戲使用縮小後的內嵌版本。

## 驗證

本機 278 項測試通過，包含六館任意館門之間的可達路線、正門與碰撞位置、直橫式鏡頭、新模型透明材質與體積、原角色／文物／選課流程，以及原有不鎖 FPS 的 60／120／144 Hz 驗證。

桌面 Edge 實際檢查全景、遠山分層、春秋史館帶路抵達、入館、室內方向鍵行走、展櫃與近看竹簡。尚未量測各裝置的實際 FPS，不將幾何與光影的減量視為硬體效能數字。
