# 青丘原創 3D 素材

`create_qingqiu.py` 以 Blender 4.5 建立十個原創模型：九尾狐、墨團精、符紙妖、石甲猿妖、樹、石柱、符紋燈、狐紋玉墜、護腕與展旗。

本次網格與配色由腳本製作，沒有取用《天堂》《仙境傳說》的角色、怪物、介面或素材。九尾狐的文化形象參照《山海經・南山經》，遊戲招式與器物另行創作。

輸出位於 `godot/village/assets/qingqiu-*.glb`。植被在 Godot 以 MultiMesh 共用；模型輸出包含 BakedLight 頂點色，讓單純材質在不使用動態陰影時仍有明暗層次。

可編輯 `qingqiu-models.blend` 與腳本、模型一起放在本次交付資料夾。人物沿用專案現有動漫模型，授權見 `art/anime/LICENSES.md`。

此為第一區可玩版的原創風格模型。完整企劃的其他區域與更細緻動畫仍需後續製作。
